# 🌤️ Medical Weather Bulletin Engine

An automated, data-driven infographic generator designed for Pharmaceutical Medical Representatives. It creates medically accurate weather bulletins tailored for allergy and asthma patients.

## ✨ Features
* **🌡️ Smart Medical Risk Calculator:** Translates raw weather data (Dust, Humidity, Wind) into actionable clinical risk levels (Low, Moderate, High) for Respiratory and Nasal health.
* **🌿 Algorithmic Pollen Estimation:** Intelligently estimates pollen levels based on seasonality, wind speed, and humidity, bypassing regional API limitations.
* **🚨 Storm Alert Mode (Red Alert):** Automatically transforms the visual design into a red warning card during extreme weather events (e.g., severe dust storms).
* **🎨 Clean HTML-to-Image Rendering:** Uses `html2image` to generate crisp, professional PNG infographics without overlapping pharmaceutical branding.

## 🚀 Tech Stack
* Python 3
* Open-Meteo API (Weather & Air Quality Data)
* HTML2Image & CSS (Rendering Engine)
* Pillow (Image Optimization)
